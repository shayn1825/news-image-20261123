# news-image-20261123

THE WORLD TODAY — the news of Monday 23 November 2026 in one image.

`main.py` (Python 3 standard library only) draws a 1024x1024 newspaper
front page: COP31 collapses in Antalya, Russian missiles in Poland,
FIFA votes on the 2035 Women's World Cup, Taiwan bans short selling,
128 states agree to draft killer-robot rules, plus BepiColombo,
Marquez and the Indonesia factory fire in brief.

Run it:

    mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py

It writes `out/entry.png`, deterministically — two runs produce
identical bytes.
